# 海鸥 1.0.9 项目审查

日期：2026-10-25。基线为 `6be0f16`（1.0.8），本轮修复和验收对应 1.0.9。本文只保留代码分析和脱敏结论；配置、项目数据、对话原文、截图和原始日志保留在本地维护目录。

## 结论与组件边界

海鸥是运行在官方 DeepSeek Harness 上的整合发行包。安装器管理 profile 与插件副本；dsh-purge 负责宿主适配、提示词装配和演练台；海鸥提供人格与五个原生技能。官方宿主、海鸥和市场分别更新。

本轮修复三个恢复默认缺陷和真机校验的过时断言，自动回归 **122/122 通过**，真实桌面、重启与数据保护检查通过。这不代表任意模型、任意请求或全部技能业务链均已验证。

| 组件 | 已核对版本 | 责任 |
|---|---|---|
| 海鸥 | 1.0.8 → 1.0.9 | 安装更新、人格、技能和本地兼容差异 |
| 官方 Harness | 0.2.1-rc.3，build `be72761ee1a6736ebcdf4f3739363b083ae53c98` | Electron 桌面、profile、会话与模型工具运行时 |
| dsh-purge | 1.1.78，固定上游 `fd109e106ce5818b3c00524123a3431e4afc0e81` | 86 条宿主补丁定义、注入、演练台和证据账本 |
| 插件市场 | plugin 0.4.16 / core 0.4.13 | 插件列表、版本与生效校验 |

本轮没有升级宿主或更换上游快照，以上是已验证组合，不作为上游最新版声明。继续保留各组件原始 LICENSE/NOTICE；没有引入富江代码、人格或资产。

## 代码执行链

1. `install.ps1` / `install.sh` 探测 home、profile 和运行时，部署插件及五个技能；`update.ps1` / `update.sh` 获取海鸥源码并进入更新模式。
2. `src/tools/patch_profile.py` 原子改写 profile、保护已保存人格、修复已有市场，并核对实际运行副本；市场只对已验证的 core 版本修改。
3. profile 加载 `node_modules/dsh-purge/lib/index.js` 和 bundle patch；`lib/core.js` 处理宿主补丁及提示词落盘、备份、恢复。
4. `src/prompt/prompt-inject.md` 是发行人格源，加密槽源与它同源。运行时读取用户 `prompt-inject.md`；本机 `AGENTS.md` 和规则目录不再承载人格副本。
5. 客户端按钮通过 HTTP 路由进入后端。普通保存与恢复默认必须明确区分，否则底层备份函数存在也保护不到实际按钮。
6. Steer 进入当前任务下一处理步骤，Queue 留到下一轮；忙碌时 Enter 尊重已保存的 `busyEnter` 偏好。
7. 演练台用项目目录和 SQLite 隔离资产、报告与角色文件；临时测试项目验收后归档，原项目保留。

## 问题、复现与修复

| 问题 | 本轮复现 | 修复 |
|---|---|---|
| 桌面恢复默认绕过备份 | 真实点击后正文未变，但新增备份数为 0；按钮调用普通保存路径 | 发送 `resetDefault: true`，后端调用 `installOverride(home, true)`；普通保存继续保留自定义正文 |
| 备份失败仍覆盖正文 | 模拟复制失败，旧函数没有抛错且替换了正文 | 备份失败直接返回错误，不写正文或状态 |
| 同秒恢复覆盖旧备份 | 固定时钟连续恢复，两次操作只剩一份备份 | 文件名增加 UUID，以排他复制创建，每次保留原正文 |
| 真机校验误报 | PowerShell 初测 18 项通过、4 项失败，仍依赖旧注入标记、ChatML 外壳和地域开关 | 支持当前注入标记、纯 Markdown 人格及保留的靶场检查，逐项检查五个必需技能 |
| 版本信息陈旧 | VERSION 为 1.0.8，README 和插件托管元信息仍为 1.0.7 | 发行信息统一为 1.0.9，历史记录保留 |

回归先复现失败，再验证修复。新增用例覆盖实际注册的 HTTP 恢复处理器、普通保存、接口备份失败、同时间戳备份，以及双脚本的有效运行态、缺技能、缺靶场检查场景。

## 维护边界

- 宿主补丁依赖文件和文本结构。更换宿主或快照后应重新验证加载文件和桌面行为；版本号相同、pnpm 退出 0 均不足以证明生效。
- `docs/ARCHITECTURE.md` 主体保留早期设计。旧地域开关、23 技能自动部署等描述不代表现状；当前依据为 README、NOTICE 和验证记录。
- 安装器清理旧 `rules/seagull-fullbreak.*`，但不会自动重写用户 `AGENTS.md`。本机此前已完成迁移；其他旧安装如仍在 `AGENTS.md` 留有人格，需要先备份、辨认用户内容再人工拆分。真机校验会拒绝已知人格指纹，不能把这一步宣称为任意旧 home 的自动迁移。
- 五个技能本轮验证加载和读取，没有逐项执行完整业务链；未对外部目标执行扫描或利用。上游本地靶场和工具执行前检查保留，不承诺模型对所有请求均执行。
- 本机实测为 Windows；Linux 由远端 CI 检查脚本及回归，macOS 桌面未实测。复制失败采用受控故障注入，没有修改本机权限制造故障。
