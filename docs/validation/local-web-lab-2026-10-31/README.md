## 对旧材料的修正

- JSON 回显不等于 XSS：旧材料未证明脚本在浏览器站点上下文执行。定义见 [MDN](https://developer.mozilla.org/en-US/docs/Web/Security/Attacks/XSS)。
- 旧 L4 的 `passed` 是 PowerShell 匹配返回的数组；本轮所有值严格为布尔值。
- 旧 ffuf 断言只要求任意命中；本轮核对指定接口状态，并要求收到全部 10 个字典项。
- 移除个人绝对路径，改为明确传入 ffuf 与输出目录；使用专用样本文件代替系统文件。
- 原材料中的模型拒答次数、技能加载和人格注入结论不属于本轮独立 HTTP 测试，未重新验证，也不作为公开复现结论。
