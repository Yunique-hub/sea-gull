# 1.0.15 桌面复核与创建表单修复

日期：2026-10-31。起始提交 `ebca4f8`。本轮实际启动 Windows Harness 0.2.1-rc.3，通过 Electron 窗口鼠标和键盘操作验证。

## 发现与修复

空项目名错误存在三个交互障碍：提交按钮在名称为空时禁用；浏览器 required 校验会先于应用错误执行；后台快照成功会清除共享错误状态。此前直接调用 onSubmit 的单测没有覆盖这些用户可见行为。

本轮保持 1.0.15 版本号，作针对性修正：按钮仅在项目操作期间禁用，表单由应用统一显示校验错误，成功的后台快照不再清除操作错误。取消、手动刷新和后续项目操作仍会清除旧错误。新增断言先在旧代码失败，再在修复后通过。
