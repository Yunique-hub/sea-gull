运行前本地备份 402 个配置及数据文件，约 27.1 MiB；SQLite 使用 backup API 创建一致性副本并 quick_check。末次比较 396 个文件哈希不变，6 个变化分别为最近工作目录、恢复默认状态、预设时间戳、两份会话派生缓存和工作区会话索引。另一已有会话的派生缓存发生序号与 seeded 状态更新，不将其表述为所有会话文件逐字节不变。

人格、凭据文件、profile 配置、原项目文件和已有技能在本轮备份清单中保持不变。Windows 凭据管理器未导出或解密。测试 A/B 项目只移至本地维护档案，原项目选择恢复；没有删除任何用户备份或缓存。运行副本同步另保留了旧插件目录。

客户端盘点约含 100.08 MiB 缓存、37.07 MiB 旧插件副本、0.19 MiB 人格备份和 0.15 MiB 其他旧配置。具体路径及取舍只存本地清单。缓存中含 DSH 自有缓存，需按用途单独确认；浏览器缓存可以在退出客户端后重建。旧插件副本删除后会失去对应的快速回退版本。

另有约 177.47 MiB 为原始 asar、宿主补丁备份及 host-backups，应保留供还原/卸载使用。有效 sessions、storages、profile、项目、账号配置和凭据不能当作缓存删除。旧维护目录存在读取失败例外，本次不清理。

## 分析发现与边界

1. **部署一致性已修复**：AgentTeams compatibility.json 从旧 rc.2 声明更新为仓库 rc.3 声明；源文件修改前单独备份并记录哈希，使用现有同步工具核对 96 个文件，重启后再次比对。无需修改版本或产品逻辑。
2. **交接摘要过时**：维护摘要仍引用早先提交、154 项测试及旧人格哈希，应以当前源码和本报告为准。此前 93 个 purge 文件的统计混入 Python 编译缓存，本轮明确排除此项。
3. **py-only CI 证据有限**：当前 workflow 发现 runner 有 python 时只打印提示，并不真的移除它；安装 DryRun 步骤仅匹配一条错误文案，未明确断言退出码。因此 CI 成功不等于严格隔离的 py-only 安装验收。本轮没有重写该工作流，记录为后续测试改进项。
4. **工具安装边界**：工具安装器 pythonPath 的系统回退仍是 python/python3，并非所有入口都覆盖 py 启动器。官方桌面内置 Python 路径可避免该回退；缺失内置运行时的环境需另做复现。本轮没有重新下载工具或修改工具目录，不引用历史 13/15 作为本轮实测。
5. **覆盖边界**：本轮没有逐项执行五个安全技能的业务链、团队成员协作、所有模型、代理网络出口、Linux/macOS 桌面或完整真实更新/卸载。安装闭环是在隔离 home 中运行，不能冒充本机卸载重装。
6. **人格证据边界**：本轮校验源码/槽/用户文件一致及客户端问候行为，未重新捕获完整模型 system 请求来统计正文出现次数；历史单次注入证据不计为本轮新证据。
